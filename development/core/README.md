# AIFPatent 核心开发记录

本目录保存核心系统的历史开发与迁移记录，不属于当前产品使用文档。

文件：

- `development-log.md`：AIFPatent 独立仓库建立后的核心工作记录；
- `migration-record.md`：从 AI4Patent 迁移到 AIFPatent/LangGraph 的完成记录。
- `idea-serpapi-design.md`：IDEA 接入 SerpAPI 主检索与详情回退的已实施设计；
- `independent-claim-evidence-repair.md`：独立权利要求证据门前移、Provider 回退和候补修复的已实施设计。

当前产品架构以 `../../docs/aifpatent-architecture.md` 和 `../../docs/aifpatent-architecture-diagram.md` 为准。后续独立功能应建立自己的 `development/<feature>/` 开发域，不继续向 `docs/` 写入开发日志或规划文档。
