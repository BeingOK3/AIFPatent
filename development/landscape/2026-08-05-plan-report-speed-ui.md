# Landscape 后续三任务规划（2026-08-05）

目标：在 v4 真实运行验收基础上，按顺序完成三件事，全部在 124.223.158.48 远程服务器开发、测试并以中文提交 git 留档。

## 任务一：做出更好的报告（宏观总结）

现状：Report 4.0 只有粒度化输出（趋势候选、代表专利、专利明细、限制），没有宏观层面的整体总结，用户体感“输出太多、没有体现趋势”。

方案：报告升级 4.1.0，新增程序化 `macro_summary`：
- 总体规模：公开文本数、分析单元数、方向数、机构数；
- 整体时间脉冲：按时间桶聚合全部方向的单元数，并判定整体涨/平/跌（样本不足则如实标注，不虚构）；
- 方向概览：按单元数排序的 Top 方向（含变化类型）；
- 机构概览：Top 机构；
- 变化分布：各变化类型的趋势候选数量；
- 宏观叙述：程序模板生成中文一句话总结，只引用真实计数。
前端在报告顶部展示“宏观趋势总结”卡片。
